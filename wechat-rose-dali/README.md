# WeChat Rose Dali

一个适合在微信里打开的动态单页网站。

效果：

- 中间展示一朵动态玫瑰
- 页面写着“大柳”两个字
- 背景有漂浮花瓣动画
- 纯静态页面，方便直接上传 GitHub

## 文件结构

```text
wechat-rose-dali/
  ├─ index.html
  ├─ styles.css
  ├─ app.js
  └─ .nojekyll
```

## 本地打开

直接双击 `index.html` 即可预览。

## 上传到 GitHub

最简单的方式是把 `wechat-rose-dali` 目录里的文件上传到一个新的 GitHub 仓库根目录。

然后开启 GitHub Pages：

1. 进入 GitHub 仓库 `Settings`
2. 打开 `Pages`
3. 在 `Build and deployment` 里选择从当前分支部署
4. 选择根目录 `/`
5. 保存后等待生成公开链接

生成后会得到一个可访问网址，把这个网址发到微信里打开即可。

## 适用场景

- 表白页
- 纪念页
- 微信分享落地页
